# SW Computer Repairs and Custom Builds

Static marketing and work-order website for SW Computer Repairs and Custom Builds.

## Stack

Vanilla HTML, CSS, and JavaScript with no build step or dependencies. Deploys directly to GitHub Pages.

## Files

- index.html: page structure and content
- styles.css: black and white theme, responsive layout
- script.js: mobile nav, year stamp, form validation and submission
- logo.svg: pixel art tabby technician logo

## Setup

1. Create a free access key at https://web3forms.com and replace YOUR_WEB3FORMS_ACCESS_KEY in index.html.
2. In the repository settings, enable GitHub Pages from the main branch root.
